# Legacy Service (No Golden Path)

This template scaffolds a **minimal Node.js service without `AGENTS.md`**.

Use it for **Flow 1 contrast**: scaffold a repo, open it in Cursor, and ask for a
health-check endpoint — the agent has no repo-level conventions to follow.

Compare with **New Microservice (Golden Path)**, which includes `AGENTS.md`,
`.cursor/rules`, CI stub, and structured logging guidance.
